# Triage Labels

The installed engineering skills use five canonical triage states.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and suitable for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgement |
| `wontfix` | `wontfix` | Will not be actioned |

Category labels remain `bug` and `enhancement` where those labels are used.
