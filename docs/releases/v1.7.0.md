## Product boundary

The canonical product is the Agent Skill under `skills/design-studio/`. v1.7 contracts Studio, Review and Document as first-class lanes over the same source-boundary, evidence and acceptance model. Visual direction and evaluation remain source-blind; deterministic helpers remain internal implementation details behind `skills/design-studio/runtime-contract.md`.

The root Claude Code files remain an optional, thin adapter for host discovery and Studio/Review invocation. A standalone CLI remains deferred under `docs/decisions/0003-claude-adapter-and-deferred-cli.md`. Growth Arsenal remains separate optional composition rather than a runtime dependency.

## Version authority

`skills/design-studio/SKILL.md` is the canonical product version. `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json` retain matching version metadata because the optional Claude publishing surfaces require it. Workflow and eval data do not duplicate the product version.
