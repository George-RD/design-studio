## Product boundary

The canonical product is the Agent Skill under `skills/design-studio/`. Supported runtime behavior is self-contained there and may use host capabilities, but it has no runtime dependency on Impeccable, Emil Kowalski's skills, Growth Arsenal, Claude plugin files, or repository research tooling.

The root Claude Code files remain optional discovery and invocation adapters. A standalone CLI remains deferred under `docs/decisions/0003-claude-adapter-and-deferred-cli.md`; #53 found no repeated cross-host command need that justifies another public interface.

## Outcome

v1.6 therefore has one supported product model: a portable, self-contained Agent Skill with a local method kernel and deterministic runtime seam. Host adapters can expose that same contract but cannot change quality behavior. External design systems remain credited research inputs, and Growth Arsenal is optional composition rather than a dependency.
