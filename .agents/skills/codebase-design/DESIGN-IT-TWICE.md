# Design It Twice

When an interface design is consequential, generate several genuinely different alternatives before choosing one.

## Process

1. Frame the constraints, dependencies and required behavior without presenting a favored solution.
2. Ask 3+ parallel agents for radically different interfaces: minimal surface, maximum flexibility, common-case optimization, and ports/adapters where relevant.
3. Each proposal states its interface, example usage, hidden implementation, dependency strategy and trade-offs.
4. Compare them by depth, locality and seam placement, then recommend one or a deliberate hybrid.
