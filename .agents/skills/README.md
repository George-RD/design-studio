# Installed Matt Pocock engineering skills

This repository contains editable, repo-owned copies of a deliberately selected engineering subset from `mattpocock/skills`:

- `setup-matt-pocock-skills`
- `to-spec`
- `to-tickets`
- `triage`
- `implement`
- `tdd`
- `code-review`
- `codebase-design`

Source repository: `https://github.com/mattpocock/skills`
Pinned source revision: `6654f6b60cd9d5be8b54c6fafe44346dabeb3b76`
Licence: MIT; see `LICENSE.mattpocock-skills`.

The subset covers planning, issue decomposition, implementation, test-driven development, architecture vocabulary and review without importing unrelated productivity skills. The normal install route for a fresh repo is `npx skills@latest add mattpocock/skills`; these checked-in copies are intentionally editable and pinned. Review upstream deliberately before updating them.
