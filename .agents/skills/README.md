# Installed Matt Pocock engineering skills

This repository contains editable, repo-owned copies of a deliberately small subset of `mattpocock/skills` needed for planning and issue workflow:

- `setup-matt-pocock-skills`
- `to-spec`
- `to-tickets`
- `triage`

Source repository: `https://github.com/mattpocock/skills`
Pinned source revision: `6654f6b60cd9d5be8b54c6fafe44346dabeb3b76`
Licence: MIT; see `LICENSE.mattpocock-skills`.

These were selected instead of importing the whole repository so Design Studio does not accumulate unrelated prompt surface. Update deliberately after reviewing upstream changes. The normal install route for a fresh repo is `npx skills@latest add mattpocock/skills`; these checked-in copies are intentionally editable and pinned.
