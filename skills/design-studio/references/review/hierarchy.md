# Visual lens: hierarchy and rhythm

Judge what the eye sees first, second and third, and how visual intensity changes through the surface. Use rendered evidence only.

## Hierarchy per screen

- State the actual first, second and third visual signals. If that is unclear, hierarchy is weak.
- Verify the most important content/action owns the strongest combination of scale, contrast, position and space.
- Check supporting content is legible without competing equally.
- Check density matches importance: important material should not be cramped while filler receives the most room.
- Apply the five-second test: a new user understands what this is and what to do, or the primary operational task and current state.
- On mobile, verify hierarchy was recomposed rather than merely stacked.

Do not claim an exact font size, margin, grid or colour value from a screenshot. Describe the visible relationship.

## Rhythm across the surface

- Repeated structures should be clearly identical or intentionally different; near-duplicates feel accidental.
- Long pages need variation in density, scale, media, colour field or interaction while remaining one system.
- Repeating the same section template creates monotony; unrelated devices create chaos.
- Section transitions should support the narrative/task rather than reset the design.
- Alignment and reading paths should feel deliberate at desktop and mobile.
- Quiet regions should earn and frame intense regions.

## Severity

- `blocker`: primary task/action is invisible, reversed or defeated by competing signals.
- `quality`: hierarchy is flat, rhythm monotonous/chaotic, or mobile reading order is materially weaker.
- `polish`: local scale, alignment or pacing refinement.

For every finding name the viewport, region, visible issue and user consequence.
